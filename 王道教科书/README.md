## 下载

八份 PDF 通过 [Git LFS](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-git-large-file-storage) 存储。安装 Git LFS 后克隆即可获得完整文件：

```bash
git lfs install
git clone https://github.com/wan-6767/11408.git
cd 11408
git lfs pull
```

下载单本时，打开上表中的文件链接并点击下载原始文件。普通 Git 克隆或仓库 ZIP 可能只得到 LFS 指针，完整 PDF 应以文件清单中的大小和 SHA256 为准。

## 重新生成

需要 Python 3.10 或更高版本，以及 Poppler 的 `pdftotext`、`pdftoppm`；PDF 完整性检查使用 Ghostscript。生成脚本仅使用 Python 标准库。

从仓库根目录进入 `王道教科书`，先创建候选输出目录，再以计算机网络为例生成：

```bash
cd 王道教科书
mkdir -p 候选输出
python3 参考资料/reflow_network.py --book network \
  --source-pdf '原教材/2027王道《计算机网络》.pdf' \
  --output '候选输出/2027王道《计算机网络》题目裁剪版.pdf' \
  --report '候选输出/2027王道《计算机网络》题目裁剪版.qa.txt' \
  --dpi 250
```

其他教材的 `--book` 分别为 `os`、`ds`、`co`。重新生成后应完整执行质量标准中的检查流程。
