# 四本教材习题重排版质量标准与检查规范

本文档记录本次四本王道教材习题重排版使用的实现方法、参数、缺陷修正经验和交付检查标准。后续处理同一本教材的其他版本，或处理结构相近的教材时，应以本文档作为基线，再根据实际页面记录必要的特殊裁剪规则。四本教材共用同一套“源像素裁剪、逐题配对、全量渲染、人工复核”的流程。

## 1. 目标与范围

重排版的目标是：

1. 只保留各章节“习题精选”中的题目和“答案与解析”中的对应答案，排除知识点正文。
2. 每道题后直接放置对应答案和解析，题目与答案之间有明确但不过大的间距。
3. 保留原书中的文字、公式、图片、表格、流程图、时序图和答案附图。
4. 通过原始页面像素裁剪完成排版，不重新识别和重打文字，避免公式、上下标、选项、图文关系被改变。
5. 每一页四周保留稳定白边，题目或答案不得被相邻内容覆盖、截断或贴到页面边缘。
6. 允许一个很长的题目或答案跨页，但只能在安全空白处分页，并且不得丢失任何像素内容。
7. 每个习题小节的第一道题前必须加入章名和小节名定位标题，方便在整本资料中快速定位。

本次章节定位版最终结果如下，页数为包含章名和小节名定位条后的实际页数：

| 教材 | 习题小节 | 题目答案对数 | 成品页数 |
|---|---:|---:|---:|
| 操作系统 | 16 | 760 | 228 |
| 数据结构 | 30 | 805 | 264 |
| 计算机组成原理 | 27 | 683 | 203 |
| 计算机网络 | 28 | 643 | 184 |

各教材只处理源书中实际存在“本节习题精选”或“本节试题精选”的小节；没有习题精选的小节不会人为补页。

加入定位标题后的版本应以“章名 + 小节名 + 第一题”的顺序开始每个习题小节。例如：

```text
第 1 章 计算机网络体系结构
1.1 计算机网络概述
01. 题目……
```

章名和小节名都从源 PDF 页面像素中裁剪，不能用 OCR 结果重新打字。定位标题只用于导航，不得引入知识点正文或答案内容。

## 2. 核心实现原则

### 2.1 OCR 只用于定位

使用 `pdftotext -bbox-layout` 读取源 PDF 的文字框坐标，用于识别：

- “本节习题精选”和“答案与解析”的章节边界；
- 每道题的编号起点；
- 下一道题或下一节正文的边界；
- 每行文字的 `yMax`，以检查裁剪是否包含完整字形。

OCR 文本不直接写入成品 PDF。成品中的文字、公式和图形全部来自源 PDF 渲染后的 RGB 像素。

### 2.2 先建立题目答案索引，再裁剪

处理顺序必须固定为：

1. 跳过目录等前置页面，识别所有“本节习题精选”标题。
2. 为每个习题标题寻找同一小节的“答案与解析”标题。
3. 在两个标题之间按 `01、02、03...` 的顺序识别题目起点。
4. 在答案标题和下一节正文之间按同样规则识别答案起点。
5. 检查每个小节题目数与答案数完全相等。
6. 按题目索引一一配对，再对每一对分别裁剪题目和答案。

编号识别只接受“下一个期望编号”，避免把图中的数字、解析中的编号或表格数字误当成新题。综合题重新从 `01` 编号时，只有在题目行/答案行满足相应标记条件时才接受编号重置。

### 2.3 裁剪原始像素，不拼接识别文字

每个内容块从源页面的渲染图中裁剪，再以整页 RGB 图像的形式写入新的 PDF。这样可以保持：

- 原字体和字形；
- 公式、上下标、分数和特殊符号；
- 图片、表格和边框；
- 题目文字与附图原有的相对位置。

### 2.4 加入定位标题

每个习题小节只在第一道题之前加入一次定位标题：

1. 章名使用该章页面顶部的源书运行标题，例如“第 1 章 计算机网络体系结构”。
2. 小节名使用距离“本节习题精选”最近的源书二级标题，例如“1.1 计算机网络概述”。
3. 章名与小节名分别裁剪为完整宽度的白底图像条，再按 3 pt 间隔拼接。
4. 小节名与第一道题之间保留 8 pt 空白；后续题目不重复插入标题。
5. 如果题目起始页是奇偶页的通用页眉，章名可以从相邻页同章运行页眉取得，但必须在索引中记录源页坐标。

定位标题的检查重点是：标题必须属于当前章和当前小节，不能带入页码、上一章标题或知识点正文。

以下参数是本次最终成品使用的实际值，不能随意缩小。若要修改，应重新执行完整 QA。

| 源内容横向裁剪 | x = 52..490 pt | 去掉源页外侧无关区域 |

## 4. 精确边界规则

### 4.1 普通题目或答案

对于同一页上的相邻内容块：

- 起点使用该题编号行的 `yMin`；
- 终点先取下一块起点的 `y - 0.5 pt`；
- 查找当前块中所有位于终点前的文字行 `yMax`；
- 若 `max(yMax) + 1.25 pt` 更靠下，则把终点向下延伸；
- 延伸最多不超过下一块起点 `6 pt`，避免吞入下一块内容；
- 最终裁剪前再加上下各 `4 pt` 像素留白。

这样可以解决 OCR 的 `yMin` 和 `yMax` 发生轻微重叠时，按下一行 `yMin` 裁剪会切掉当前行下沿的问题。

### 4.2 小节末尾

如果当前块是本小节最后一道题或最后一个答案，边界使用 `4 pt` 间隔，而不是普通的 `0.5 pt`。原因是下一节标题的抗锯齿像素可能向上延伸，使用过小间隔会把下一节标题的碎片带入答案。

### 4.3 跨页块

如果题目或答案跨越源页：

- 首页从题目/答案起点开始；
- 中间页使用源内容范围 `64..706 pt`；
- 末页在下一编号或小节边界处结束；
- 每段都分别加上下留白；
- 不因为跨页而重新排版、缩放或重打内容。

## 5. 附图、表格和跨栏内容

附图和表格必须随所在题目或答案一起裁剪，不能只保留文字。

本书第一章存在一个特殊跨栏区域：第 1.2 节第 36 题的时序图向下延伸，接近第 37 题左栏文字。如果直接使用普通整栏裁剪，会发生题目之间互相带入。处理方式是：

- q36 使用左侧题目区域和右侧时序图区域的合并裁剪；
- q36 顶部从 `348 pt` 开始，排除上一题选项的残片；
- q37 使用 `410..469.45 pt` 的独立区域；
- 对 q37 右侧时序图延伸区域进行白色遮罩，避免 q36 图形重复进入 q37。

任何类似跨栏、跨题、图形压住文字的页面，都必须登记为特殊规则，并单独生成题目答案预览进行检查。不能用“普通裁剪看起来差不多”代替确认。

四本教材的结构差异也要在索引阶段登记：

- 《操作系统》本次识别到 16 个有习题精选的小节，3.1 q7 和 5.2 q38 使用独立特殊区域规则。

- 《计算机组成原理》4.3 的综合题在源书中印为 01..06、09，而对应答案印为 01..07；经内容核对后按顺序配对，保留两侧原始印刷编号，不人为改写题号。
- 《计算机网络》除 1.2 节 q36/q37 的时序图跨栏规则外，3.8 的星号编号知识点和部分图形化小节标题也必须按源像素边界处理；不能把下一小节知识点正文带入上一节答案。

## 6. 页面拼接与分页规则

每组题目答案按以下顺序加入输出流：

```text
题目全部裁剪段
14 pt 空白间隔
答案全部裁剪段
8 pt 空白间隔
下一题
```

页面内容从 14 pt 页边距之后开始，结束位置距离页面底部保留 14 pt。

一个题目或答案放不下时，分页函数只能在连续至少 4 行的真实空白处切开，并且切分前后都必须保留至少 18 pt 的内容片段。找不到安全空白时，整块移动到下一页；对于极少数超大块，才使用保留全部像素的硬分页兜底。任何分页都不能静默丢弃像素。

页面自然出现少量空白是允许的，尤其是最后一道长答案的续页。判定标准是内容完整、没有被截断或覆盖，而不是强行把每一页填满。

## 7. 自动化检查标准

每次生成完整成品后必须执行以下检查，并保存结果。

### 7.1 生成前检查

- `python3 -m py_compile reflow_network.py` 通过；
- 源文件路径、版本和输出文件名明确；
- 不覆盖旧版成品，使用新的版本名；
- 记录渲染 DPI 和所有特殊区域。

### 7.2 结构和数量检查

- 习题小节数量与教材实际章节一致；
- 每小节题目数等于答案数；
- 总配对数量与章节清单相符；
- 每组输出顺序必须是题目在前、对应答案在后；
- 每个习题小节的第一道题前必须出现正确的章名和小节名；
- 不应出现知识点标题、章节正文或下一节标题碎片。

本次四本教材的实际结果见第 1 节表格；其中《计算机网络》章节定位版为 `28 sections`、`643 pairs`、`184 output pages`。

### 7.3 PDF 完整性检查

使用 `pdfinfo` 检查：

- 页数；
- 页面尺寸；
- 未加密；
- PDF 版本和文件可读性。

使用 Ghostscript 空设备完整遍历：

```bash
gs -q -dNOPAUSE -dBATCH -sDEVICE=nullpage "输出.pdf"
```

命令退出码必须为 0，不能有解析错误。

### 7.4 全量页面像素检查

将输出 PDF 以较低分辨率渲染全部页面，逐页检查：

- 图片尺寸一致；
- 不存在全白空白页；
- 四周边缘没有非预期内容越界；
- 没有明显横向或纵向黑边异常；
- 页面内容不是被截成零高度或极小片段。

四个成品均完成全量渲染；空白页为 0，边缘越界为 0，图片尺寸和页面尺寸均保持一致。

本轮 2026-10-10 复核的全量低分辨率扫描结果为：操作系统 228 页、数据结构 264 页、计算机组成原理 203 页、计算机网络 184 页，共 879 页；每页尺寸均为 259 x 419 像素，空白页、边缘越界页和异常尺寸页均为 0。

### 7.5 文字边界检查

使用源 PDF 的文字框做反向核对：每个普通裁剪段最后一行的 `yMax` 必须落在该段底边以内，并且保留安全余量。四本教材都要逐块统计文字行截断数和最大越界；本次成品的普通裁剪段文字行截断数均为 0，最大越界为 0。

特殊裁剪区域不使用普通文字边界算法，必须进行独立高分辨率预览。

## 8. 人工复核标准

自动检查不能替代视觉检查。每次完整生成后必须完成以下三轮复核：

### 第一轮：全量缩略图

把全部页面制作成联系表，按约 30 页一张进行浏览，检查：

- 是否有白页、断页或意外重复页；
- 题目后是否确实紧跟答案；
- 每个小节起始处的章名、小节名是否正确且没有页码残片；
- 页面上下左右是否有异常大白边；
- 是否有明显重叠、黑块、白块或截断；
- 章节开头、中间和结尾的版式是否一致。

### 第二轮：重点页面高分辨率

至少检查以下类型：

- 第一章开头和第一个分页点；
- 题目、答案都跨页的页面；
- 含表格、流程图、公式或多栏图形的页面；
- 小节结束和下一小节开始的页面；
- 最后两页；
- 视觉上内容最密集和最稀疏的页面。

放大检查题目底部、答案底部、图片边框、表格边框和页边距，不能只看缩略图。

### 第三轮：特殊区域单独复核

所有特殊题目单独导出成小 PDF 或 PNG，逐块确认：

- 题号没有带入上一题残片；
- 题目文字完整；
- 图形没有重复或被遮挡；
- 答案解析没有覆盖题目或后续内容；
- 白色遮罩只覆盖应排除的区域。

本次网络 q36/q37 时序图、操作系统 q7/q38、数据结构上述 19 个区域以及组成原理 q49/a20 都按此方法单独复核；重点检查图形节点、表格边框、代码块末行、答案底部和遮罩边界，没有发现覆盖或缺图。

## 9. 常见缺陷与修正经验

| 缺陷 | 原因 | 修正方法 |
|---|---|---|
| 答案底部少一行或少半个字 | 使用下一行 `yMin` 作为终点 | 改用当前最后行 `yMax + 1.25 pt`，并限制最大延伸 |
| 答案截图盖住题目 | 题目、答案间隔太小或块边界重叠 | 题目后固定 14 pt 空白；重新核对每个块的边界 |
| 下一题编号残片出现在上一题底部 | 边界贴到下一题起点 | 相邻题使用 0.5 pt 边界间隔，视觉异常时单独增大 |
| 下一节标题残片进入最后答案 | 小节末尾仍使用普通间隔 | 小节末尾使用 4 pt 间隔 |
| 上一题选项出现在特殊题顶部 | 跨栏区域的普通起点不适用 | 特殊区域从实际题号上方安全位置重新确定起点 |
| 跨栏图形重复进入下一题 | 图形延伸超过下一题的左栏起点 | 用独立裁剪和白色遮罩去掉重叠区域 |
| 分页把字或图切成两半 | 任意行分页 | 只在连续空白运行中分页；找不到时整块移页 |
| 页面四周贴边 | 只裁剪内容，没有成品页边距 | 固定四周 14 pt 页边距，块本身再加 4 pt 上下留白 |
| 页面出现很大的无意义空白 | 过度保守地移动整块或边界过宽 | 先减小普通边界间隔；保留安全余量，不牺牲完整性 |
| 只看几页导致后半本偏移 | 使用全书固定坐标或只验证开头 | 每页按自身文字框重新计算，且必须全量联系表复核 |
